# Task Management System – Frontend

## 🛠 Tech Stack

- **React (Vite)**
- **Tailwind CSS**

### Install Dependencies

```bash
cd frontend
npm install
```

### Run the Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Shared Components

Reusable UI components are located in: `src/components/shared/` :

- `Button.jsx`
- `Input.jsx`
- `Modal.jsx`
